# Birdcam
Birdhouse-Camera with object detection

-You need and Birdhous, a Raspberry Pi (works on 2/2B but better with 4 with 4 or 8GB) and a Kamera (USB or original Pi Cam)
The Applikation is weiten in Python and uses an Tensorflowmodel which detects preTrained Objects und saves Fotos and a Short Video if the object is Bird.
